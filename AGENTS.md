# Repository Guidance

When turning YU's notes or other source material into skills, consolidate
repeated guidance and omit details that do not improve the agent's work.
Preserve meaningful distinctions, explicit preferences, and relevant source
provenance; treat examples as illustrations, not universal requirements.

Keep skills English-first, retaining Chinese wording where it preserves useful
meaning. Prefer extending an existing skill over creating overlapping skills,
and add supporting files only when they serve a clear purpose.

For prose and user-facing writing in this repository, use the
[clear-writing skill](skills/clear-writing/SKILL.md) alongside relevant
task-specific guidance.

For coding tasks in this repository, use the
[pragmatic-coding skill](skills/pragmatic-coding/SKILL.md).

For complex, multi-stage work in this repository, use the
[adaptive-reflection skill](skills/adaptive-reflection/SKILL.md).

For research-idea discovery, novelty assessment, or implementation and
experiment planning for a chosen direction in this repository, use the
[research-ideas skill](skills/research-ideas/SKILL.md).

For a requested paper-integrity or evidence audit in this repository, use the
[research-integrity skill](skills/research-integrity/SKILL.md).
