# Adaptive Reflection: Source Notes

Source: YU's instruction in the project conversation. The
[adaptive-reflection skill](../skills/adaptive-reflection/SKILL.md) applies it
to difficult, evolving work at meaningful decision points. It preserves the
ability to proceed normally when there is no actionable concern.

## 反思检查（用户原文）

> 在我们最近反复讨论的问题背后，有没有一个更深的问题/更精准，完美的设计，是我们一直在绕着它走，却没有真正挖掘，实现或是被解决？
> propose next steps or important things to note. if all good, we can move on normally.
>
> 1. 先检查问题有没有错误前提，逻辑跳跃和信息缺失。
> 2. 不要迎合我本来的判断，要独立判断，区分事实，预测和主观观点。
> 3. 涉及 数字，文章，人物和结论时尽量核实来源。
> 4. 不同意就直接指出并给出依据，风险和替代解释。
> 5. 还要主动提醒我忽略的变量，成本和偏差。
