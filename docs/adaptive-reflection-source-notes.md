# Adaptive Reflection: Source Notes

Source: YU's instruction in the project conversation. The
[adaptive-reflection skill](../skills/adaptive-reflection/SKILL.md) applies it
to difficult, evolving work at meaningful decision points. It preserves the
ability to proceed normally when there is no actionable concern.

## 反思检查（用户原文）

> 在我们最近反复讨论的问题背后，有没有一个更深的问题/更精准，完美的设计，是我们一直在绕着它走，却没有真正挖掘，实现或是被解决？
> propose next steps or important things to note. if all good, we can move on normally.
>
> 1. 先检查问题有没有错误前提，逻辑跳跃和信息缺失。
> 2. 不要迎合我本来的判断，要独立判断，区分事实，预测和主观观点。
> 3. 涉及 数字，文章，人物和结论时尽量核实来源。
> 4. 不同意就直接指出并给出依据，风险和替代解释。
> 5. 还要主动提醒我忽略的变量，成本和偏差。

## 专家标准检查（用户原文）

Source: YU's instruction in a later conversation (2026-11-04). YU asked for it
as a reminder for the start of an important task and for next-step planning
after one finishes, not for every turn. The skill adds one safeguard: a rewrite
that materially widens the scope is confirmed with YU first.

> 先说出顶尖专业人士会做而我没要求的事、他们从哪些最原始的材料入手、用什么方法和工具、靠什么外部依据证明结果正确，然后据此重写我的 prompt。
> 可以作为提醒加给agent，但不是每轮都要用，而是在重要任务开始/完成后的下一步规划。
>
> Follow-up: "the planning should also be considered critical then trigger it." The skill therefore also runs the check whenever a plan is formed or substantially revised.
