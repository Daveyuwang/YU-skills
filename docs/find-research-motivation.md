# FIND RESEARCH MOTIVATION

1. 先限定范围，再找核心动机。

- 检索该研究领域的代表性工作。阅读原文，查找公开代码和数据集，重点解释每篇论文要解决的问题，关键假设和局限性。区分论文的结论与你的推测，近期工作与经典方法都要涵盖，保留阅读记录。

2. 用 “不一致”作为切入点，查清范围。

- 很多idea其实是现有方法处理不好某类特殊情况。
- 沿着【该方向】不一致这个切口，继续查已有方法处理这类问题的方式。分析这些方法依赖什么条件，还有什么没解决。如果它只能回答‘充分利用互补特征’，请追问：这个信息在实际推理时能不能获得？结合我的算力推荐一条改进路线，讲清楚输入输出和关键步骤。

3. 不要只追求创新，要找实质性差别。

- 同样的模块，放的地方不同，解决的问题可能完全不同。
- 对比这条方案与刚才检索到的最接近论文，逐项核对问题设定，关键假设和操作。说明哪些部分已经被做过，我们还多解决了什么。如果模块相似，解释为什么这样组合是必要的，而不只是换个名字。

4. 快速验证，决定去留

- 先做最小验证看方向对不对。可以不断改进和探索当前思路。
- 寻找匹配的开源基线和数据集，结合我的算力设计一个验证。说明需要改动哪里，和哪些方法对比，记录什么指标。什么结果支持我们的解释，什么结果意味着路线要修改？先交付一页研究计划（简短，清晰，易懂的描述），包含具体问题和验证安排，暂不启动完整训练。
