# Research Workspace: Source Notes

Source: [Open Research Loop](https://github.com/vukrosic/auto-research/tree/f229de2bf558982f476a2088748daf4250c48088),
reviewed at commit `f229de2bf558982f476a2088748daf4250c48088`.

The [research workspace template](../templates/research-workspace/README.md)
retains the source's useful ideas: record the research objective and constraints,
ground experiments in a baseline and a testable question, leave durable result
references, update the next plan from evidence, and keep a resumable handoff.

The adaptation uses a small set of plain Markdown files. It does not require the
source's planning hierarchy, fixed status vocabulary, agent setup, or automated
dispatch. Matching evaluation conditions depends on the research question;
equal step counts are useful for some comparisons but are not a universal rule.
