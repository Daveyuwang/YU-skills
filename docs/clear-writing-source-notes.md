# Clear Writing: Source Notes

Source: YU's general-writing guidelines pasted into the project conversation.
The structural examples match the installed
[Stop Slop](https://github.com/hardikpandya/stop-slop) reference, and the pasted
text points to its `phrases.md`. The adaptation uses that reference and keeps
its [MIT notice](../skills/clear-writing/LICENSE-stop-slop.txt) with the skill.

The [clear-writing skill](../skills/clear-writing/SKILL.md) adds YU's explicit
preferences to avoid em dashes and generally avoid `within` and `across`. It
groups the repeated patterns into practical instructions rather than copying
the full pattern tables. The wording reference keeps examples for focused
cleanup.

The adaptation preserves facts, necessary qualifications, exact quotations,
and explicit task requirements. It does not invent an actor to force active
voice, remove a meaningful adverb, or omit a required list item merely to
avoid a three-item list.
