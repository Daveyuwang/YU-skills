# Visual Assets for Research Figures

Find graphics that explain real objects, actors, or concepts and match the
figure's visual style. Search for specific concepts and compare candidates;
use an appropriate vector asset where practical. Preserve source accuracy and
keep assets independently movable in editable deliverables when possible.

## Search for icons

Run a live keyword search for the requested element before opening any
worked-example asset links. Use the catalog's search or a site-filtered web
query with terms that name the concept and, if useful, the style or format.
For example, search for `AI robot`, `retrieval database`, or
`outline document`. Compare results at the final display size and match
stroke weight, fill, and color to the figure. Look for related icons from
the same pack when the figure needs several.

1. Start with [Flaticon](https://www.flaticon.com/). Use the site's search or
   a site-filtered web search. Its free tier offers PNG for eligible icons.
   Check which formats are available on the user's plan. [Flaticon plans](https://www.flaticon.com/pricing)
2. Search [SVG Repo](https://www.svgrepo.com/) next if Flaticon lacks a good
   match, the required SVG, or suitable terms. Read the license shown on the
   individual icon page. [SVG Repo licensing](https://www.svgrepo.com/page/licensing)
3. Use [The Noun Project](https://thenounproject.com/) as an optional fallback.
   Check the icon's license and download options. CC BY icons on the free
   tier require credit. [Noun Project icon licenses](https://help.thenounproject.com/hc/en-us/articles/200509798-What-licenses-do-you-offer-for-icons)

## Confirm the file and usage terms

- Open the exact asset page and verify the creator, available file formats,
  and whether the desired download is free or requires a paid plan. If
  the page or terms are unavailable, report the gap or choose a verifiable
  alternative.
- Prefer SVG when the figure needs scalable or editable paths. A transparent
  PNG is suitable when its resolution is sufficient at the final size. Keep
  it as a separate raster component in the editable figure. If the brief
  requires vector paths, continue searching when only PNG is available.
- Check whether the license permits the intended publication, edits, and
  any sharing of editable source files containing the asset. Record the
  asset URL, creator, license, access date, and required credit with the
  figure source. Put required credit in the published output where the
  license and venue allow. Check permission before extracting assets from
  other papers.

## Present candidates

For an icon search or an important figure element, show two or three
verified candidates. Include at least one result from the current keyword
search whose asset page is absent from the worked examples. Try a synonym
or the next catalog if the first query yields no suitable new result.

For each candidate, link the asset page and give the verified format,
whether that format is free or paid, and any required credit. Show a
preview when available. If fewer than two options can be verified, give
the ones you checked and report the gap. Explain the fit and recommend one.
Ask the user to choose when the options meaningfully change the figure's
style, interpretation, or delivery. Use a clear match in the draft when
the choice is easy to reverse.

to choose the visual style.

## Other sources

- [Bioicons](https://bioicons.com/): life-science illustrations, with licenses
  that vary by asset. Check the selected icon's author and license.
- [Servier Medical Art](https://smart.servier.com/): medical and biological
  illustrations; check its current attribution requirements and the specific
  asset's terms.
- [Lucide](https://lucide.dev/): general-purpose icons for software, people,
  devices, and workflows. Check its [license](https://lucide.dev/license).
- [Canva](https://www.canva.com/): a design editor with Free, Pro, and other
  content categories. Consult the [content license](https://www.canva.com/policies/content-license-agreement/)
  for the specific element and intended publication; Pro content has
  one-design and standalone-use restrictions. Branded and Education content
  may have additional restrictions.
- [BioRender](https://www.biorender.com/): science-specific illustrations and
  templates. Check the account plan and publication license before submission;
  access to an asset does not by itself grant publication rights.

## Working with Canva

If the user requests Canva and its app or connector is available, use the
available tools to create, inspect, or revise a design, following the tool's
own authorization and preview requirements. Tool availability does not prove
that the user's account is connected or that catalog elements can be searched
or inserted programmatically. Check the current capabilities and report any
limits. User-supplied or independently licensed graphics may be uploaded if the
requested task and their terms allow it. Review the resulting figure's
scientific content, visual quality, and editability before delivery.
