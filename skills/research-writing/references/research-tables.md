# Research Tables

Use these as YU's default preferences for paper tables. Adapt them to the
content, accessibility, and the venue's instructions; preserve the underlying
data and requested deliverable.

## Structure and alignment

- **Use few rules.** Avoid vertical and double horizontal lines. Use whitespace
  and necessary single horizontal rules to distinguish the header, groups,
  and table end.
- **Make columns explicit.** Name metrics, units, and relevant aggregation or
  statistical conventions so readers can interpret the values. Present
  configuration, conditions, or component choices in separate columns when
  useful rather than packing them into method names. Define symbols clearly.
- **Align consistently.** Left-align text; align comparable numerical values
  on their decimal points and use consistent precision for the same metric.
  Short integer or simple numeric columns may be centered. Coordinate each
  heading with its column and preserve the underlying values when rounding.
- **Group by meaning.** Organize rows or columns by research question, method
  family, or experimental setting. Use group labels, whitespace, or fine
  horizontal rules to communicate the hierarchy.

## Caption, notes, and emphasis

- Place the table caption above the table unless the venue specifies
  otherwise. Briefly state what is compared; place needed definitions and
  additional explanations in notes below the table. Avoid repeating a long
  discussion from the main text.
- Highlight selected key numbers rather than making the whole table compete
  for attention. Use restrained color when suitable, keep each color's meaning
  consistent, and explain the metric direction or highlighting rule. Combine
  color with weight or another non-color cue so the distinction remains
  readable in grayscale. Keep ties and rankings faithful to the data.

## Editable and legible output

Use consistent typography and render mathematical notation as text or LaTeX
math as appropriate. Retain a native editable table or reproducible source;
avoid replacing it with a raster image when editable output is required.
Check the final display size for readable type, spacing, wrapping, and
overflow. Do not invent missing values, settings, or statistical details.
