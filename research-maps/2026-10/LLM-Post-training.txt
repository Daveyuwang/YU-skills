LLM Post-training

Post-training turns a model that only continues text into a useful assistant. For example, a pre-trained model given "Write a poem about cats" may just write more requests like it, while a post-trained model writes the poem. This map covers fine-tuning, preference data, reinforcement learning and reasoning. Reading raw text is in the LLM Pre-training map.

Each paper below has an arXiv link and one simple sentence. Results are the numbers the authors report, and they were not rerun here. Links were checked against arXiv on November 2, 2026.

The 7 branches
Fine-tuning: Training on examples of instructions and good answers. First paper: Finetuned Language Models Are Zero-Shot Learners.

Preference data and RLHF: Teaching a model from which of two answers people liked more. First paper: InstructGPT.

Reinforcement learning: Letting a model try answers and learn from a score. First paper: DeepSeek-R1.

Reasoning: Getting a model to think in steps, and only as long as it needs. First paper: Chain-of-Thought Prompting.

Data for post-training: Choosing which problems the model practices and in what order. First paper: Reasoning Curriculum.

Measuring the result: Tests that say whether post-training helped. First paper: the MATH dataset.

Character and behaviour: The way a model acts, including habits such as agreeing too much. First paper: Constitutional AI.

Words you will see
Fine-tuning: training an existing model a bit more on new examples.

Supervised fine-tuning: fine-tuning on fixed examples with known good answers.

LoRA: a small add-on that is trained instead of the full model.

Forgetting: when learning something new damages a skill the model already had.

Preference data: pairs of answers where someone marked the better one.

Reward model: a model that gives an answer a score, trained to match people's preferences.

RLHF: reinforcement learning from human feedback, which raises the score from a reward model.

DPO: direct preference optimization, which learns from preference data with no reward model.

Reinforcement learning: learning by trying things and getting a score.

Rollout: one answer the model produces during training.

RLVR: reinforcement learning with verifiable rewards, where a program checks whether the answer is right.

PPO and GRPO: two popular reinforcement learning rules. GRPO compares each answer with others for the same question.

Chain of thought: the steps a model writes out before its final answer.

Overthinking: writing far more reasoning steps than the problem needs.

Test-time compute: extra work spent while answering, such as thinking longer.

Distillation: training one model to copy another model's outputs.

Reward hacking: getting a high score without really doing the task.

Sycophancy: agreeing with the user even when the user is wrong.

Fine-tuning

QLoRA (May 2023): Uses LoRA on a compressed model, so that a large model needs less memory. https://arxiv.org/abs/2305.14314

Llama 2 (Jul 2023): Describes in full how a chat model was fine-tuned and made safer. https://arxiv.org/abs/2307.09288

Instruction data

Zephyr (Oct 2023): A recipe that aligns a small model using data from larger models and DPO. https://arxiv.org/abs/2310.16944

Avoiding model collapse (Jul 2026): Keeps quality from falling when each new model learns from data made by the last one. https://arxiv.org/abs/2607.17043

Only direction matters (Sep 2026): Argues that fine-tuning depends on how a model changes, not only on how much. https://arxiv.org/abs/2609.13680

Mid-training

Model Spec Midtraining (May 2026): First teaches the model what its behaviour rules mean, so that later training generalizes better. https://arxiv.org/abs/2605.02087

Forgetting
Sharpness-Aware Pretraining (May 2026): A short SAM stage cuts forgetting by 31% after post-training. https://arxiv.org/abs/2605.02105

On-Policy Replay (May 2026): Reduces forgetting by replaying earlier tasks with the model's own answers. https://arxiv.org/abs/2605.29495

Learning without Overwriting (Oct 2026): A theory of why self-distillation can keep old knowledge while adding reasoning. https://arxiv.org/abs/2610.05200

Preference Packing (Feb 2026): Packs batches to cut training time by at least 37%. https://arxiv.org/abs/2602.24082

Reinforcement learning
Good papers to start with
PPO (Jul 2017): The classic rule that most language model reinforcement learning builds on. https://arxiv.org/abs/1707.06347

Process and outcome feedback (Nov 2022): Compares rewarding each step with rewarding only the final answer. https://arxiv.org/abs/2211.14275

Let's Verify Step by Step (May 2023): Shows that checking each step beats checking only the final answer. https://arxiv.org/abs/2305.20050

DeepSeek-R1 (Jan 2025): Showed that reinforcement learning with verifiable rewards can produce strong reasoning. https://arxiv.org/abs/2501.12948

Demystifying RL post-training (Aug 2026): A primer for people who are new to this area. https://arxiv.org/abs/2608.24949

Understanding Reasoning (Jul 2026): Connects pre-training with reinforcement learning in a controlled test. https://arxiv.org/abs/2607.16097

λ-GRPO (Oct 2025): Unifies GRPO versions by learning how much each token should count. https://arxiv.org/abs/2510.06870

Mu-GRPO (May 2026): Reuses older rollouts for about 2x faster training. https://arxiv.org/abs/2605.17570

GRPO beyond English (Aug 2026): A large study of GRPO in other languages. https://arxiv.org/abs/2608.13698

Some questions for inspiration
What does GRPO's standard deviation step change?: Train a small model on a number game with and without this step, then compare which problems it improves on. https://arxiv.org/abs/2607.00152

Does a length penalty hurt accuracy on a small model?: Add a small penalty for each extra word, then plot length and accuracy for several penalty sizes. https://arxiv.org/abs/2603.00296

Which problems teach a small model the most?: Train on easy, medium and hard problems separately, then test each model on all three. https://arxiv.org/abs/2610.39056

Can you measure forgetting?: Fine-tune a small model on one task, then measure how much worse it got at what it could already do. https://arxiv.org/abs/2601.18699

How much do wrong labels hurt DPO?: Flip a share of the labels in a preference dataset, train a small model, and plot quality against the share flipped. https://arxiv.org/abs/2509.23564
